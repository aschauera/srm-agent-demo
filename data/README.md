# Fictional SRM Demo Seed Data

These CSVs are generated by [03-import-sampledata.py](../scripts/03-import-sampledata.py). They use
the column definitions in `schema/tables/*.json` and stable `DemoKey` references for parent/child
lookups.

- All suppliers, DUNS-like identifiers, financial values, GSA/Coface/D&B results, communications,
  adverse events, and archive references are synthetic.
- Placeholder URLs use the reserved `.invalid` domain and are never retrieved.
- Contact addresses use `example.com`.
- No credentials, real supplier documents, or real third-party records are included.
- The conversion bands and risk thresholds are explicitly illustrative, marked `Draft - demo only`,
  and are not approved MAGNA policy.
- Zero-spend suppliers do not receive One-Page Summary records.

The data covers every GSA pre-check and review path, recent and stale Coface data, fuzzy-match
candidates for no-DUNS suppliers, the day-3/day-7 reminders, multi-year distressed-supplier analysis,
non-financial risk signals, audit events, linked Early Warnings, and archive categories.

To regenerate the CSVs without connecting to Dataverse:

```powershell
python scripts\03-import-sampledata.py --export-only
```

To idempotently import them to the configured DemoPRE target:

```powershell
python scripts\03-import-sampledata.py
```

Verify the live tables, solution membership, row keys, and branch coverage:

```powershell
python scripts\verify-datamodel.py
```
