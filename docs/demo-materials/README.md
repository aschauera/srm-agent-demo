# SRM Demo Materials

All materials here are synthetic presentation/test fixtures. They are not supplier records,
source financial statements, approved ratings, or MAGNA policy. Do not send them outside the
DemoPRE demonstration.

The [SUP-012 attachment set](./supplier-financial-statements/) contains twelve plain-text files
with values aligned to the fictional working-paper rows in `data/working_papers.csv`. Use them
only with the optional file-flow rehearsal in the [live demo guide](../09-demo-script.md).

The files test Dataverse file upload and the 12-document completeness gate. They do not test
PDF/image handling, OCR, financial extraction, or rating generation.

The new [PDF analysis package](./pdf-analysis/README.md) contains actual digital, image-only,
and unreadable PDF fixtures plus contradictory supporting disclosures for the approved agent-led
demo. It supersedes the text fixtures for the document-input proof, not for claiming a completed
live extraction pipeline.
